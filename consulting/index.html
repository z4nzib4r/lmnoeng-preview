How we work

Three ways to get to the answer.

The method follows the problem. Results come back as a written report, a spreadsheet you can reuse, or software.

01

Existing computer models

When an established model fits the problem, we set it up, run it, and report what it means.

  • EPANET
  • HEC-RAS
  • HEC-HMS
  • TR-55
